Apartment Homelab Network

Omada SDN, wall APs, VLANs, and Pi-hole DNS in a small apartment network.

Goal

Build a reliable home network that separates trusted devices from IoT and streaming boxes, keeps DNS filtering local, and is easy to manage without enterprise hardware.

Hardware

  • TP-Link Omada gateway / controller
  • EAP235-Wall access points
  • Managed switch (as needed for VLANs)
  • Pi-hole host (existing homelab machine or small VM)

Design

  • Trusted LAN — laptops, phones, admin access
  • IoT VLAN — isolated smart devices, no lateral access to the LAN
  • Media / TV VLAN — Android TV boxes and streaming devices
  • DNS — Pi-hole as primary DNS; router/DHCP hands that address to clients
  • Wireless — SSIDs mapped to VLANs on the wall APs

What I configured

  • Omada site, controller, and AP adoption
  • SSID to VLAN mapping
  • DHCP scopes per subnet
  • Firewall / inter-VLAN rules (IoT can reach internet, not the admin LAN)
  • Pi-hole upstream DNS and client lists

Current status

In progress. Core wireless and VLAN plan are in place; still tightening isolation rules and documenting the IP plan.

What I learned

  • Wall APs are a better fit for an apartment than ceiling units.
  • VLANs only help if DHCP, DNS, and firewall rules all match the same plan.
  • IoT and TV boxes need internet, not access to every other device.
